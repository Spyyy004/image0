# image0.dev

Professional image tools that run entirely in your browser.

No uploads.  
No tracking.  
No registration.

## Why image0.dev
Most image tools upload your files to a server.
image0.dev processes everything locally using modern browser APIs.

Your images never leave your device.

## Features (V1)
- Image compression
- Resize images
- Format conversion (PNG / JPG / WEBP)
- Batch processing
- EXIF metadata removal

## Privacy
All processing happens client-side.
There is no backend and no file storage.

## Tech Stack
- Browser APIs (Canvas, Web Workers)
- No backend
- No analytics by default
